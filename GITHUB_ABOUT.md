# GitHub "About" — xtracticle-saver

Set in the repo's **Settings → About** (description + topics), or from the CLI with
`gh repo edit`. Not a file in the repo — GitHub reads About from repo settings.

---

## Description (single line, well under the 350-char limit)

```
Android share target for xtracticle.com: share an X post, get a PDF (image posts) or Markdown (text posts) in Downloads. A thin WebView driver that clicks the site's own buttons. Desktop Tampermonkey userscript included.
```

Shorter alternative (if you prefer punchier):

```
One-tap Android share target that saves X posts as PDF or Markdown via xtracticle.com — no rebuild, just driving the site.
```

## Notes for whoever sets it

- "About" = the short description box on the repo homepage, plus the topic chips below the
  repo name. Both are metadata, not files.
- The description shows on the repo landing page and in search results, so it should stand
  alone without the README.
- Topics drive GitHub search/discovery — `android`, `kotlin`, `webview` are the load-bearing
  ones; the rest are descriptive.
